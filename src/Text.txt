## react intro

    What is React?

    1) React is a JavaScript library (not a framework) developed by Facebook (Meta) for building user interfaces (UIs), especially Single Page Applications (SPAs).

    2) It helps developers build reusable UI components that update efficiently when data changes.

    Instead of reloading a whole webpage when something changes, React updates only the parts of the UI that need to change.

    -------
    Why do we need React?

	It makes UI development faster, cleaner, and more efficient.

	Provides a better user experience with smooth updates without page reloads.

## useState()

    useState is a react hook that allows you to add state (data that can change over time)
    to a functional component.

    Normally, in js  functionality, variables dissappear after the functional runs.
    but with useState ,react remembers value between re-renders.

    syntax:

        const [state,setState]=useState(initialvalue)

        state-- the current value of the state variable.
        setState--- a function that updatess the state
        initialvalue--- the starting  value of the state..

## Routing in react and Nested routing

    Routing means navigating b/w different pages in a web app without refreshing the browser.

    In teaining website,clicking a linnk reloads the whole page.

    In react (Single page Applications) , routing lets us changes the view without reloading.


        Better performance .
        Smooth user experience
        control over navigating.



    commend:npm install react-router-dom


    structure:

    <BroWserRouter>
    <Routes>
    <Route  path="address path"  elements={<Home/>}/>
    <Route  path=""  elements={<About/>}/>
    <Route  path=""  elements={<Service/>}/>
    </Routes>
    </BroWserRouter>

    BroWserRouter

        It is the main wrapper component for  routing in react App.
        It Enables  Navigation using the browser URL (history API).
        Without this routing will ot work.


    Routes
        It contains all the  <Route/> component
        It tells React Router which component to show for which path.
        Only one route will shown at a timme.

    Route:
        defines specific URL path and which component should load for the path.
